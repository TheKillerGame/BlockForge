Installation Guide

Get Block Forge up and running in just a few minutes

⚡

Quick Start

Follow these simple steps to install and launch Block Forge on your computer.

1

Download Block Forge

Head to our download page and select your Minecraft version from the dropdown menu. Then click the download button for your operating system (Windows, macOS, or Linux).

💡 All versions are included in one installer - selecting a version just sets the default when you launch!
2

Run the Installer

Locate the downloaded file and double-click to run it.

  1. Find BlockForge.zip in your Downloads folder
  2. Right-click the ZIP file and select "Extract All..."
  3. Open the extracted folder and find BlockForge-Setup.exe
  4. Double-click to run the installer
  5. If Windows SmartScreen appears, click "More info" then "Run anyway"
  6. Follow the installation wizard prompts
  7. Choose your installation directory (default is recommended)
  8. Click "Install" and wait for completion
  1. Find BlockForge.zip in your Downloads folder
  2. Double-click to extract the ZIP file
  3. Open the extracted folder and find BlockForge.dmg
  4. Double-click the DMG to mount the disk image
  5. Drag the Block Forge icon to your Applications folder
  6. If blocked by Gatekeeper, go to System Preferences → Security & Privacy
  7. Click "Open Anyway" next to the Block Forge message
  1. Find BlockForge.zip in your Downloads folder
  2. Extract the ZIP: unzip BlockForge.zip
  3. Navigate to the extracted folder: cd BlockForge
  4. Make the file executable: chmod +x BlockForge.AppImage
  5. Run the installer: ./BlockForge.AppImage
  6. Alternatively, right-click → Properties → Permissions → Allow executing as program
3

Launch Block Forge

Once installed, you can launch Block Forge from:

  • 💻 Desktop shortcut - Double-click the Block Forge icon
  • 🔍 Start Menu / Applications - Search for "Block Forge"
  • 📁 Installation folder - Run BlockForge.exe directly

Troubleshooting

Having issues? Check these common solutions.

First, make sure you've extracted the ZIP file before running the installer. Right-click the ZIP and select "Extract All...". Then run the BlockForge-Setup.exe from the extracted folder. If Windows SmartScreen appears, click "More info" then "Run anyway". If issues persist, temporarily disable your antivirus during installation.

Block Forge requires Java 17 or higher. Download it from Adoptium (recommended) or Oracle. After installing Java, restart Block Forge.

Try these steps:

  1. Allocate more RAM in Settings (minimum 4GB recommended)
  2. Update your graphics drivers
  3. Disable mods and try launching vanilla first
  4. Delete the .blockforge folder and reinstall

Optimize your settings:

  1. Lower render distance (8-12 chunks recommended)
  2. Disable fancy graphics and smooth lighting
  3. Install OptiFine from the Mods menu
  4. Allocate more RAM if you have it available
  5. Close background applications

Check these common causes:

  1. Verify your internet connection
  2. Make sure you're using the correct server version
  3. Check if the server is online
  4. Disable VPN if you're using one
  5. Allow Block Forge through your firewall

System Requirements

Minimum

  • OS: Windows 10, macOS 10.14, Ubuntu 18.04
  • CPU: Intel Core i3 / AMD Ryzen 3
  • RAM: 4 GB
  • GPU: Intel HD 4000 / AMD Radeon R5
  • Storage: 500 MB + game files
  • Java: Version 17 or higher
Recommended

Recommended

  • OS: Windows 11, macOS 12, Ubuntu 22.04
  • CPU: Intel Core i5 / AMD Ryzen 5
  • RAM: 8 GB or more
  • GPU: NVIDIA GTX 1060 / AMD RX 580
  • Storage: SSD with 2 GB free
  • Java: Version 21 (latest)
